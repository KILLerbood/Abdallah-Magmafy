# Magmafy · موقع الوكالة (نسخة 3D)

موقع ثابت (HTML / CSS / JS) بدون أي سيرفر أو build. Three.js وGSAP والخطوط محفوظة داخل `assets/`.

## التشغيل محليًا
```
python -m http.server 8080
```
ثم افتح http://localhost:8080 (لازم سيرفر، فتح index.html مباشرة لا يشغّل الـ modules).

## إيميل الحجوزات
عدّل `assets/js/config.js` وضع الإيميل الذي تصله الحجوزات في `bookingEmail`.
الإرسال عبر FormSubmit: أول حجز يرسل رابط تفعيل لمرة واحدة على هذا الإيميل، اضغطه وبعدها كل الحجوزات توصل مباشرة.
إن فشل الإرسال، يظهر للعميل زر يرسل الحجز بالبريد، مع زر Google Calendar وملف .ics.

## الأقسام
- Hero ثلاثي الأبعاد: نواة "ماجما" بألوان الهوية وحولها حلقة صور أثاث حقيقية.
- فيلم شرح متحرك (6 لقطات) يعمل تلقائيًا عند الوصول إليه.
- الخدمات (8) في شريط أفقي مثبّت.
- دراسة السوق وتحليل المنافسين لدول الخليج الست (عينة توضيحية).
- مقارنة Magmafy بالوكالات العامة واستوديوهات 3D والمستقلين.
- رحلة عميل تفاعلية في 6 خطوات.
- كنبة 3D قابلة للتخصيص (قماش، أرجل، مقاس، سعر).
- 4 مواقع صغيرة شغالة على Cover-flow ثلاثي الأبعاد.
- أرقام السوق بمصادرها، آلية العمل، 4 باقات بدون أسعار، أسئلة شائعة.
- حجز اجتماع بتقويم (اليوم + الوقت + نوع الاجتماع).
